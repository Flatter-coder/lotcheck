About this report. "Verified" excludes any single dealer pass that returned more used or new units than one Alberta rooftop plausibly carries — a signal worth checking, not one dealer's real lot. "Raw" is the count before that check. This is what LotCheck has read, on the days it read it — never a claim about the whole Alberta market, and it updates only on the days a crawl actually ran (the crawl runs nightly and reads only the dealers whose sites allow it and whose platform we can read).
